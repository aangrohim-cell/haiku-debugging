A deterministic Node 22 entrypoint that writes a three-line, 5-7-5 debugging haiku into `entry.txt`.

The judged text is exactly the three lines in `out/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
